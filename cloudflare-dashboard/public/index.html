3 setup steps
  1. 01
    Deploy the ClipBridge Worker

    Use the cloudflare-dashboard root folder for the separate clipbridge-windows Worker. This does not change your garden website.

  2. 02
    Set up private status storage

    Bind a Workers KV namespace as STATUS_STORE, then create separate VIEW_TOKEN and INGEST_TOKEN secrets in Cloudflare.

  3. 03
    Connect the PC and this browser

    Enable Cloudflare monitoring in ClipBridge Windows using INGEST_TOKEN. On this page select Connect dashboard and enter VIEW_TOKEN.

What needs to be configured?

In Cloudflare, bind a Workers KV namespace to STATUS_STORE, and set separate VIEW_TOKEN and INGEST_TOKEN secrets. In ClipBridge Windows, enable monitoring and enter the Worker URL with the ingest token. This dashboard uses only the viewer token.
